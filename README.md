# Персональный сайт образовательного куратора Университета «Синергия»

Современный конверсионный сайт для экспертов по поступлению, менеджеров приемной комиссии и образовательных консультантов Университета Синергия. 

Сайт разработан по аналогии с персональными страницами топ-брокеров недвижимости: акцент на личный бренд, доверие, подбор факультетов, финансовые выгоды (рассрочка 0%, скидки, маткапитал) и быстрый перевод диалога в Telegram / WhatsApp.

---

## 🚀 Структура и возможности сайта

1. **Главный экран (Hero) + Taplink-визитка:**
   - Высококонверсионный заголовок с оффером поступления без нервов и очередей.
   - Персональная карточка куратора с реальным фото, статусом «Онлайн», быстрыми кнопками в Telegram/WhatsApp и цитатой.
   - Интерактивные кликабельные стикеры-мемы («ЕГЭ без паники», «В IT с головой», «Рассрочка 0%»).

2. **Блок преимуществ персонального брокера образования:**
   - Почему абитуриенты и родители выбирают поступать через личного куратора, а не через общую очередь.

3. **Интерактивный каталог программ и факультетов:**
   - Фильтрация по уровням: **Все**, **Колледж (9-11 кл.)**, **Бакалавриат**, **Магистратура**, **100% Онлайн-вуз**.
   - Популярные программы: IT & ИИ, Предпринимательство и Бизнес, Графический дизайн и Геймдев, Юриспруденция, Психология, Медфарм.
   - Кнопки моментального перехода к деталям и расчету стоимости.

4. **Финансовый блок (Скидки, Рассрочка, Маткапитал):**
   - Прямая рассрочка 0% от университета без процентов и переплат.
   - Скидки до 30% при бронировании или переводе.
   - Оплата 100% материнским капиталом (государственная аккредитация).
   - Налоговый вычет 13% и льготный кредит под 3%.

5. **Интерактивный 60-секундный тест (Лид-магнит):**
   - 4 шага: текущее образование -> интересная сфера -> формат обучения -> выдача персонального бонуса.
   - Автоматическая передача ответов теста прямо в диалог Telegram / WhatsApp куратору!

6. **Мемы и студенческий вайб:**
   - Легкий юмор, отражающий боли абитуриентов («Очередь в приёмку vs зачисление через куратора в мессенджере»).

7. **Отзывы студентов и родителей:**
   - Социальные доказательства зачисления в колледж, бакалавриат и дистанционное обучение.

8. **FAQ и модальное окно обратного звонка:**
   - Ответы про аккредитацию, диплом гос. образца, отсрочку от армии и стоимость услуг.

9. **Мобильная Taplink-панель (Bottom Sticky Bar):**
   - Для пользователей смартфонов внизу экрана закреплены кнопки перехода в Telegram, WhatsApp и тест.

## ⚙️ Персональные данные и контакты куратора

Вся настройка контактных данных и интеграций находится в файле [`script.js`](file:///d:/ворк/сайт/script.js):

```javascript
const CONFIG = {
  managerName: "Максим Лунгу",
  telegramUsername: "mss44zak",            // Ваш Telegram @mss44zak
  whatsAppPhone: "79990000000",             // Ваш номер WhatsApp (в формате 79991234567)
  defaultPhone: "+7 (999) 000-00-00",       // Контактный номер
  // URL вашего скрипта Google Таблицы (см. инструкцию ниже):
  googleSheetWebhookUrl: "https://script.google.com/macros/s/.../exec"
};
```

## 📊 Интеграция с CRM Google Таблицей (Пошаговая инструкция)

В проект уже включен готовый скрипт [`google_sheets_crm_script.js`](file:///d:/ворк/сайт/google_sheets_crm_script.js). Он автоматически:
1. Создает главный лист **«Все Лиды»** со статусами лидов, ФИО, контактами, выбранной программой и расчетом стоимости.
2. Создает **отдельные листы на каждый день** (например, `11.09.2026`) для оперативной работы со свежими заявками дня.

### Как подключить за 2 минуты:
1. Откройте [Google Таблицы](https://sheets.new) и создайте новую таблицу (назовите её, например: *«Синергия CRM — Максим Лунгу»*).
2. В верхнем меню нажмите **«Расширения» (Extensions) → «Apps Script»**.
3. Сотрите всё, что там написано, и вставьте код из файла [`google_sheets_crm_script.js`](file:///d:/ворк/сайт/google_sheets_crm_script.js).
4. В правом верхнем углу нажмите **«Начать развертывание» (Deploy) → «Новое развертывание» (New deployment)**.
5. Нажмите на значок шестеренки ⚙️ слева от типа и выберите **«Веб-приложение» (Web app)**:
   - **Описание**: `CRM Webhook`
   - **Выполнять от имени**: `Я` (Me)
   - **У кого есть доступ**: **`Все` (Anyone)** *(Обязательно выберите этот пункт, чтобы сайт мог отправлять данные без авторизации)*
6. Нажмите **«Развернуть» (Deploy)** и предоставьте доступ к таблице через свой Google-аккаунт.
7. Скопируйте **URL веб-приложения** (оканчивается на `/exec`).
8. Вставьте его в [`script.js`](file:///d:/ворк/сайт/script.js) в параметр `googleSheetWebhookUrl`:
   ```javascript
   googleSheetWebhookUrl: "https://script.google.com/macros/s/АК_ВАШ_КЛЮЧ/exec"
   ```

## 🌐 Как запустить сайт локально для проверки

Вы можете просто открыть файл [`index.html`](file:///d:/ворк/сайт/index.html) в браузере или запустить сервер:
```powershell
python -m http.server 8080
```
Сайт доступен по адресу `http://localhost:8080/`.
